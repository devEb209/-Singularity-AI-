# Tese dos D — arquitetura funcional V1

The D Thesis is implemented as a non-physical reasoning matrix shared by SNB and UES. Fifteen functional D domains and all `.25/.5/.75` facets are registered from V1; selection is contextual, not an unlock ladder. Evaluation generates alternatives, contextual local Perfect Points, a weighted Global Perfect Point, D-O15 optimization decisions and bounded refinement iterations. D-O15 rejects an optimization when expected quality crosses the contextual frontier. Scores are deterministic planning estimates, not proof of absolute perfection.

Artifacts use `application/vnd.snb.d-thesis+json` and `analysis.d-thesis`, with the context hash, selected D, local PP, GPP, tradeoffs, accepted/rejected optimizations and explicit `absolutePerfectionClaim:false`.

## Complement — not a replacement

`PromptTeseDosD.TXT` is a complement. It does **not** replace, reduce or turn the D Thesis into a version roadmap. It makes a graphics/physics-only reading structurally false:

- every computable real-world domain may feed UES/SNB;
- the domain catalog is open (`closedModuleList:false`);
- realism is a foundation, not a creative prison;
- D-O15 may replace a costly representation with a cheaper perceptually equivalent one;
- hardware adaptation redistributes fidelity toward the objective instead of “just lowering graphics”;
- NMN produces contextual character behavior without claiming consciousness;
- autonomous development preserves user intention and treats silence as non-authorization.

`GET /api/v1/d-thesis/registry` now exposes `scope.notLimitedToGraphicsOrPhysics`. `POST /api/v1/d-thesis/complement` builds one verified `analysis.d-thesis-complement` artifact that joins Tese dos D + Real-Life Universal + NMN + autonomy.
