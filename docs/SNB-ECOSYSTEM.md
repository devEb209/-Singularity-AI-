# SNB Gênesis — living ecosystem

The UES builds worlds. The SNB connects them. The community keeps them alive.

```text
Official SNB Assets
SNB Original Lore
Community Toolbox
Community Universes
```

Canon layers:

```text
main → archived → alternate → community → fan
```

Choosing a new main line **archives** the previous one. It does not delete it.

Moderation filters abusive tags. Silence is not unlimited authorization.

`POST /api/v1/snb/toolbox/compile` persists the catalog artifact. It is not a live public marketplace.
