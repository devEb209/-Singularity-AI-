# RRW — Renderer of the Reality of the Real World

Complement to the Tese dos D. It does **not** replace it.

```text
conhecimento + dados permitidos
→ SNB interpreta
→ Tese dos D
→ representação da realidade
→ D-O15
→ RRW
→ materialização adaptativa
→ verificação
→ refinamento
→ dispositivo
```

RRW is the UES **foundation**, not a traditional renderer.

## What this is not

- Not `asset → mesh → material → shader → raster/RT → GPU → screen`.
- Not optimized PBR / Nanite / Lumen / VSM / path tracing.
- Not Low / Medium / High of the same mesh.
- Not always-on atomic simulation.
- Not a claim of completeness (`completeReality: false`).
